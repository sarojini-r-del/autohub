# AutoHub – Vehicle Service Management System
Run: open the AutoHub folder in VS Code → install the "Live Server" extension → right-click `index.html` → "Open with Live Server".
Demo login: demo@autohub.com / Demo@123 (or register a new user). Data is stored in localStorage (clear site data to reset).
Structure: *.html pages · css/style.css · js/app.js
Flow: Home → Register/Login → Dashboard → Vehicles → Services → Book (slots + date/time) → Confirmation → Track & Bills (Advance ▶ simulates status) → Bill (Print) → Payment → Reschedule/Cancel → Feedback → Logout.
